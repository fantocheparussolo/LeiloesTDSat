Nome do projeto:
LeiloesTDSat

Explicação sobre o que se trata o projeto: 
Esse projeto consiste em um sistema desenvolvido para gerenciamento de uma casa de leilões.
O Objetivo do sistema é auxiliar no cadastro e controle de produtos disponíveis para leilão.

Tecnologias utilizadas:
- Java (NetBeans IDE 26)
- MySQL
- Git
- GitHub Desktop
